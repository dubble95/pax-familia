# 🚀 PaxFamilia 빠른 시작 가이드 (QUICKSTART)

## 1. 중앙 서버 실행 (Web 대시보드 + API)

```bash
cd /Users/jayoung/work/pax-familia
./bin/pax-server
```
- 부모 대시보드 접속: 브라우저에서 **`http://localhost:8080`** 열기
- 모바일 브라우저에서도 최적화된 반응형 UI로 접속 가능합니다.

---

## 2. 3대 기기 가상 시뮬레이터 실행 (가장 추천하는 테스트!)

안드로이드 폰, 태블릿, 윈도우 PC가 없어도 로컬에서 즉시 3대 기기가 상호 작용하는 모습을 테스트할 수 있습니다.

```bash
# 터미널 창 1 (서버 실행)
./bin/pax-server

# 터미널 창 2 (시뮬레이터 실행)
./bin/pax-sim
```

1. 브라우저로 `http://localhost:8080`을 열어둡니다.
2. 시뮬레이터를 켜면, 폰(유튜브) → 태블릿(로블록스) → PC(마인크래프트)가 번갈아가며 실시간으로 사용 시간을 소진합니다.
3. 웹 화면에서 **초록색 "사용 중" 불**이 켜지고, **남은 시간이 실시간으로 차감**되는 것을 볼 수 있습니다.
4. 웹 대시보드에서 **`[즉시 올스톱 잠금]`**을 누르면 시뮬레이터 콘솔에서 기기들이 즉시 잠기는 것을 확인할 수 있습니다.

---

## 3. 윈도우 PC에 실제 에이전트 설치 및 실행

1. 빌드된 실행 파일 복사:
   - 경로: `bin/pax-winagent.exe` 파일을 자녀의 윈도우 PC로 복사합니다.
2. 실행:
   ```cmd
   pax-winagent.exe -server http://<서버IP>:8080
   ```
3. 동작:
   - 15초마다 서버와 통신하며 남은 시간과 현재 창 제목(예: Roblox, Chrome 등)을 동기화합니다.
   - 2분 이상 마우스/키보드 입력이 없으면 유휴(Idle)로 판별하여 시간 차감을 멈춥니다.
   - 시간이 모두 소진되거나 부모가 잠금을 누르면 `LockWorkStation` API를 호출하여 즉시 윈도우 잠금 화면으로 전환합니다.
