==========================================================
🕊️ PaxFamilia (가정의 평화) 윈도우 에이전트 설치 패키지
==========================================================

[설치 방법 1 - GUI 설치 마법사]
- PaxFamiliaSetup.exe 를 더블클릭하여 안내에 따라 설치합니다.

[설치 방법 2 - 원클릭 스크립트 (권장)]
1. install.bat 파일을 마우스 우클릭 -> [관리자 권한으로 실행] 클릭
2. 부모 대시보드(https://pax-familia.fly.dev)의 [+ 새 기기 등록] 버튼을
   눌러 발급받은 6자리 숫자를 입력합니다.
3. 입력 즉시 기기 등록이 완료되고 컴퓨터 부팅 시 자동으로 백그라운드에서 동작합니다.

[제거 방법]
- uninstall.bat 파일을 관리자 권한으로 실행하면 등록된 작업 스케줄러와
  실행 파일이 깔끔하게 삭제됩니다.
